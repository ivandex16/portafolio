# Ivan Cabeza — Professional Engineering Portfolio

High-converting, performance-driven software engineering portfolio designed for technical recruiters and hiring managers.

## 🚀 Key Highlights
- **15-Second Recruiter Architecture**: Clear value proposition, immediate metrics, and direct action CTAs (Resume, LinkedIn, GitHub).
- **TypeScript End-to-End**: Showcasing full-stack capabilities across NestJS, Node.js, React.js, Next.js, and AWS.
- **Bilingual (EN / ES)**: Interactive language toggle with English by default for international USD remote roles.
- **Dark / Light Theme**: Built-in high-contrast design system inspired by Vercel and Linear.
- **Production Case Studies**: Real engineering problems, architectural tradeoffs, ACID transaction diagrams, and verified metrics.

## 🛠️ Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **SEO & Metas**: Open Graph, Twitter Cards, Schema.org Person JSON-LD

## 💻 Local Development
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deploy to Vercel
1. Push this repository to your GitHub account: `https://github.com/ivancbgz/portfolio`.
2. Connect your repo in [Vercel](https://vercel.com).
3. The default Vite settings will automatically build and deploy the project to `https://ivancbgz.vercel.app`.
